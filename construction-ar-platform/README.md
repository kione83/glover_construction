# Construction AR Platform

Minimal Expo + React Native TypeScript scaffold for the Construction AR MVP.

## What is included

- Expo application configuration
- TypeScript setup
- Single launchable app shell
- Placeholder screen aligned to the MVP module boundaries

## What is intentionally not included

- Scanning
- Object placement
- Persistence
- Navigation flows
- Backend integration

## Next steps

1. Install dependencies with `npm install`.
2. Start the app with `npm start`.
3. Open it in iOS, Android, or web from the Expo development menu.
